# 0171. The logo

- **Status:** Accepted (the project lead's own design)
- **Date:** 2026-10-26

## Problem

The app had no logo: Windows showed its plain program icon on the program file, the Start menu entry, the taskbar and the setup program. The project lead drew one and asked for it to be added.

## Decision

The logo is the project lead's: a red outlined cube (the accent red, `#C2433D`) on a dark disc (`#1B1B1B`), drawn in `assets/logo.svg`. From it, `assets/` holds:

- `icon.ico`: 16 to 256 pixels, for Windows. Put on the program file by `crates/app/build.rs` with `winresource` (MIT; a Windows-only build dependency), and on the setup program by `installer/windows/setup.iss` (`SetupIconFile`).
- `icon-256.png`: the window's title bar and taskbar icon on every system (`eframe` reads it, `window::window_icon`).
- `logo-512.png`: for pages and documents that can't show SVG.

The README shows it at the top. The PNGs and the ICO were drawn from the SVG by a browser (Chromium) at 1024 pixels and scaled down; draw them again the same way if the SVG changes.

## Consequences

- The app is recognisable in the taskbar, Start menu and installed apps.
- The logo has no letters in it, so a rename needs no new logo; it is listed in RENAMING.md all the same.
