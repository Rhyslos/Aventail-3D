# 0216. Sculpting in, the alpha release out

- **Status:** Accepted
- **Date:** 2026-10-29

## Problem

The roadmap after the texture painter ([0119](0119-roadmap-after-the-uvs.md)) had an alpha release as Phase 13 and no sculpting. On 2026-10-29 the project lead asked to take the alpha release off the plan and to add sculpting before the effects phase (Gauntlet).

## Decision

- The alpha release (Phase 13) is taken off the plan. The phases after it move up one: bug fixes and polish 13, scripting 14, rigging and skinning 15, animation 16.
- **Sculpting** is Phase 17, before Gauntlet (18). Its one aim so far: a sculpting tool focused on stylised creators. It is not planned further now; like the other later phases, it gets a planning talk and research when its time comes.
- Rules that said "until the alpha" (one development file format) keep their meaning as "until the first public release".

## Consequences

- Later phases are renumbered; decisions and history written earlier keep the numbers they used then.
