# Changelog

Every change a user would notice, newest first, in plain words.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- **Bevels stop at their neighbours, point by point.** **Stop at overlaps** is now called **Stop at neighbours** (still on as standard): a bevel is narrowed only where it would run past the end of an edge or into the bevel coming the other way, and keeps its full width everywhere else, instead of the whole bevel shrinking for one thin part. Bevels in projects made before this keep their old shape until you change one of their settings.
- **The top palette is icons only again,** without names beside Move, Scale, Rotate, Snap and Symmetry; hover over a button for its name. **Transform** (all three gizmos, T) has its own button after Rotate, and only the tool in use is lit. The select tool list looks like the app's other menus, with the tool in use highlighted.
- **Slide is Shift + Alt + drag on the Move gizmo.** Alt + drag now always moves the view, even when it starts on the gizmo, so an orbit out of habit no longer slides points by mistake.
- **Show everything has a second key, Ctrl + Shift + H,** beside Alt + H.
- **On a Mac, the app's tips and notes say Cmd** wherever they said Ctrl, as the Keys window already did.
- **A slimmer Coordinates band, and every setting in Settings.** Coordinates now shows Position, Size and Rotation side by side on one line, so the viewport is taller; an older saved layout's tall band is slimmed once. Settings has a new **Viewport display** section with Cavity, Show hard edges, Show seams, Show normals and the dice's orthographic switch, and the viewport's Display and Options menus end with **All settings…**.
- **Labels on the palettes.** Rest the mouse on the mode palette on the left and its names slide out beside the icons; click a name to use it. When the window is wide enough, the top palette writes the select tool, Move, Scale, Rotate, Snap and Symmetry beside their icons, and a small arrow beside the select tool button lists Box, Lasso and Paint select.
- **One numbered checker, in blue.** The numbered checker (Display → Surface) is now always the blue-to-green one that came with the blue accent, whatever accent colour you pick: it was the clearest.
- **The selection is easy to see.** Selected points, edges and polygons are now drawn last, thickest and in your accent colour, on top of hard edges, seams and other guides, in the viewport and the UV Editor. **Edit → Settings → High contrast** makes them bigger still, with a dark rim. **Select only visible** is now on as standard, so a box drag takes only what you can see.
- **Five modes.** Model, Points, Edges, Polygons and UV. The Object mode is gone: to move or turn an object's pivot without moving the shape, switch on **Edit pivot** (the button right under the Model mode on the left, or the Tools menu), then switch it off again.
- **"Bake into shape" is the one word.** Make editable is now **Bake into shape** (Ctrl + E), and in the edit list Freeze up to here is **Bake into shape up to here**. **Keep editable** is gone: every edit stays changeable until you bake it. Dragging the same points several times in a row now makes one edit in the list, not one per drag.
- **The Edit layers tab shows when it's wanted:** when an object with more than one layer is selected, or from **Window → Edit layers**.
- **Smoothing belongs to each object** ([#114](https://github.com/Rhyslos/Aventail-3D/issues/114)). Automatic hard edges, one switch for the whole app, is replaced by each object's own **Smoothing** in Attributes: **By angle** and its angle (30° as standard), or untick By angle for marked edges only, or **Mesh → Shading → Smooth by angle**. Marking hard or soft edges on an object smoothed by angle keeps its look: its angle's edges become marks and the object switches to its marks, so you see your change at once (one undo step). Export uses each object's own smoothing.
- **Symmetry belongs to the object.** The mirror sits at the object's pivot and moves and turns with it.
- **Tidier menus and words.** The Mesh menu is in groups (Build, Cut and join, Remove, Shading, Shape and object). Select all and Deselect live in Select only, Check for baking in UV only, and Hide, Isolate and Show everything sit together in **View → Show and hide**. Labels say one thing each ("Delete objects", "Delete points, edges or polygons", "Mark hard edges"), the UV tools say **pieces** instead of islands, and rotation reads **X, Y, Z** in the axes' colours.
- **Keys that don't bite.** In "Save changes?", Don't save is now **Alt + N** (Ctrl + D duplicates in other programs). **Esc** cancels a slit (Enter finishes it) and closes the Keys window, and E doesn't open the tool ring while a window is open.
- **The right-click menu is on as standard.** A right-click in the viewport opens the quad menu; switch it off in Edit → Settings → Interface.
- **Projects save in file format 50**, the development format with booleans, curves, improved bevels, modifiers, the Subdivide modifier with creases, lattice cages, Decimate, Scatter, Bend along curve, Shrinkwrap, Weighted normals and Live bevel with bevel weights (format 39 was the development format before them, 40 added booleans, 41 curves, 42 improved bevels, 43 modifiers, 44 Subdivide and creases, 45 lattices, 46 Decimate, 47 Scatter, 48 Bend along curve and Shrinkwrap, 49 Weighted normals): until the alpha, new settings won't need a new file version. Older projects still open; a project with booleans, curves, improved bevels, modifiers, creases, lattices, Decimate, Scatter, Bend along curve, Shrinkwrap, Weighted normals, Live bevel or bevel weights needs this version of the app.

### Fixed

- **Bevelling many edges across a UV seam is much faster:** every edge of a 32,000-polygon sphere now takes about a second instead of four.
- **Undo and redo put the selection back.** Undoing a Delete brings the shapes back selected, and redoing a Create, Group, Duplicate or Join selects what it made, as it was the first time. Before, they came back unselected.
- **Double-clicking a loop is reliable.** A double-click sometimes selected only the edge, about 3 times in 10: when you'd clicked within the second before (say, a click on the edge and then a double-click on it), the clicks were counted as a triple-click, not a double. The app now counts double-clicks itself: two clicks in the same spot within half a second, whatever came before. A quick third click straight after no longer undoes the loop either.
- **Double-click on a cylinder's rim.** A double-click on the top or bottom edge of a cylinder (any edge round an n-gon) now selects the whole rim, in the Edges and Points modes, without an inset first.
- **Alt + A in the UV Editor right after a click.** Pressing Alt + A over the UV Editor without moving the mouse first could select the whole part instead of the UV pieces, because the window briefly lost track of the mouse when Alt was pressed. It now remembers where the mouse was. H, Z and E over the editor had the same slip and are fixed too.
- **Alt + A in the UV Editor selects whole pieces.** With the mouse over the UV Editor, or in the UV mode, Alt + A now selects the UV pieces the selection is in, parted at seams, instead of the whole part of the model. Select a little of one of two overlapping pieces, press Alt + A, and move it away. **UV → Pieces → Select connected** does the same. In the viewport, Alt + A still selects the whole part.

### Added

- **Modifiers.** A shape can now have a list of **modifiers**: changes worked out live from the shape as you model it, after its edits, booleans and mirror, which you can switch off, reorder or remove at any time. Add one from its button on the **modifiers palette** (right of the viewport), **Mesh → Modifiers**, or command search; the **Attributes panel**'s new **Modifiers** section lists them with their settings, **Up**, **Down**, **Remove**, and **Show in viewport** (off, the viewport skips a slow one while exports still use it). Exports carry them, and **Bake into shape** (Ctrl + E) makes those that are on part of the shape (with the mirror before them).
- **Remesh.** The first modifier rebuilds a closed shape as an even surface of square polygons, whatever its polygons were: tidy a boolean-cut, joined or messy shape into clean quads. **Voxel size** (2 cm as standard) sets how fine; **Smooth** evens it out. Materials are kept; the UVs are replaced by a simple box projection with seams, to unwrap again. An open shape, or a voxel size so small it would need more than 2 million voxels, is left as it is, with the reason shown.
- **Subdivide.** A modifier that smooths a shape by subdividing it (Catmull-Clark): every polygon is split into quads and the corners rounded off, level by level, so a simple cage becomes a smooth shape. **Levels** for the viewport (1 as standard) and **Levels for export** (2) for exports and Bake into shape. UVs are smoothed with the shape, seams and materials kept, open borders kept in place. With **Hard edges stay sharp** (on), edges marked hard stay crisp on objects shaded by their marked edges. Heavy smoothing is worked out on another thread while you model.
- **Lattice.** **Add lattice** (the modifiers palette, **Mesh → Modifiers**, command search) puts a cage of points round the selected shapes, and gives each a **Lattice** modifier following it. Select the cage, press 1 and move its points with the gizmo or Coordinates: the shapes inside bend, squash and swell smoothly with them, live. The cage has **Divisions X / Y / Z** (2 × 2 × 2 as standard, up to 16 a side), **Interpolation** (Smooth or Linear) and **Reset points** in the Attributes panel; it's drawn as lines, picked by clicking a line, and left out of exports. Deleting it removes its modifiers in the same undo step.
- **Bend along curve.** Select a shape, Ctrl + click a curve, and Bend along curve lays the shape along it: a rope, a rail, a chain, a band round a barrel. The shape's start goes to the curve's start and the curve runs through its pivot; choose the **Axis** that runs along it (its longest side as standard), **Stretch to fit** the curve's length, slide it with **Offset**, and turn it with **Twist**. The curve stays live: reshape or move it and the shape follows. A modifier on the modifiers palette, in **Mesh → Modifiers** (under *Deform*) and in command search.
- **Shrinkwrap onto.** Select a shape, Ctrl + click another (the target), and Shrinkwrap onto moves the shape's points onto the target's surface: to the **nearest surface point**, **along the shape's normals**, or **along X, Y or Z** (a road dropped onto terrain), with an **Offset** to float it just off, and **Use selected** to wrap only chosen points. The target stays live, hidden or not. A modifier on the modifiers palette, in **Mesh → Modifiers** (under *Deform*) and in command search.
- **Scatter onto surface.** Select a surface, Ctrl + click one or more shapes, and Scatter onto surface spreads copies of them over it: on its **Points**, its **Polygon centres**, or a **Count** at **Random** (50 as standard), with a **Seed**, a least **Spacing**, **Align to surface** (on), a **Random turn**, random sizes between **Smallest** and **Largest**, an **Offset**, and **Use selected** to keep them to chosen polygons. The shapes stay objects of their own (hidden, they still scatter): edit one and every copy follows. A live modifier on the modifiers palette, in **Mesh → Modifiers** under *Generate* and in command search; exports get the surface and its copies as one mesh.
- **Weighted normals.** A modifier that shades a bevelled shape the way game models are shaded: bigger polygons count for more at each corner, so big flat faces look perfectly flat and the bevels beside them look round, without baking a normal map. **Weight by** polygon area (standard), corner angle or both, **Face influence** (75%), **Strength** (100%) and **Keep hard edges** (on, following the object's Smoothing). Its normals go into glTF and OBJ exports, and the glTF tangents for normal maps are made from them; Bake into shape keeps them. Best last in the list: a modifier after it (or an edit that moves points after baking it) drops its normals, and the Attributes panel says so. On the modifiers palette, in **Mesh → Modifiers** under *Game ready* and in command search.
- **Live bevel.** A modifier that bevels a shape's edges and keeps the bevel live: model the plain shape, and every edge sharp enough is bevelled whatever you do to it. It bevels the edges sharper than an **Angle** (30° as standard), the edges the shading shows hard, or only **marked edges**, each by its **Bevel weight**; **Width** (2 cm), **Segments** (2), **Profile** (round) and **Stop at neighbours** (on), with rounded corners where bevels meet. Added to a shape with Subdivide or Weighted normals, it goes before them; with Weighted normals last, a bevelled box's big faces shade flat. From the modifiers palette, **Mesh → Modifiers** or command search; no keys.
- **Bevel weights.** In the Edges mode, the Attributes panel's **Selected edges** section has a **Bevel weight** field (0 to 1) beside Crease: it marks the edges a Live bevel set to *Marked edges* bevels, and how much of its width. Marked edges are drawn lime green while editing. Undo, symmetry and later edits treat it like a hard edge mark.
- **Decimate.** A modifier that lowers a shape's polygon count while keeping its shape: flat areas lose the most, curves and corners the least. Choose a **Ratio** (50% as standard) or a number of **Target triangles**; **Keep UV seams**, **Keep hard edges**, **Keep material borders** and **Keep open borders** (all on) keep those lines where they are. The result is triangles, or with **Quads where flat** flat pairs joined into quads; the Attributes panel shows the **Triangles shown**. On the modifiers palette, in **Mesh → Modifiers** under *Clean up* and in command search. 100 000 triangles take about half a second.
- **Creases.** In the Edges mode, **Crease edges** and **Uncrease** (the E menu's **Creases**, in Flip normals' place, and **Mesh → Shading**) and the Attributes panel's new **Crease** field (0 to 1, under **Selected edges**) tell Subdivide how sharply to keep each edge: 1 fully sharp, 0.5 sharp for half the levels. Creased edges are drawn magenta while editing. They're recorded edits, so they undo, follow symmetry and survive later edits.
- **Rounded bevel corners.** Where three or more bevelled edges meet (a box's corner, a pyramid's tip) and the bevel has 2 or more segments, the corner is now a smooth, rounded patch of quads, like a little piece of a ball, instead of one flat polygon. It shades smoothly, keeps the materials and UVs around it, and follows the Profile (round, flat or hollow).
- **Curves, with sweep and lathe.** **Draw curve** (in **Create**, the **Alt + B** list and command search) draws a curve like a pen tool: click for a sharp point, press and drag for a smooth bend, Enter or a right click finishes, Esc cancels, Backspace takes back the last point, and clicking the first point closes the curve. Ready-made **Line**, **Circle**, **Arc** and **Spiral** curves sit beside it, with their settings in the Attributes panel. Curves are drawn as lines; in the Attributes panel, **Makes** turns one into a **sweep** (a circle, square, rectangle or another curve carried along it, with Twist and Caps: pipes, cables, rails, trims) or a **lathe** (spun round an axis: vases, bottles, wheels), which follows every change to the curve. Press 1 to move a curve's points and handles with the gizmo; double-click a point to switch it between sharp and smooth; Delete takes points away. The solid comes with UVs, seams and crisp edges, exports like any shape (a bare line exports as nothing), works in booleans, and **Bake into shape** makes it an ordinary mesh.
- **Adding points to a curve.** In the Points mode, double-click a curve's line between two points to add a point there; the curve keeps exactly its shape. Double-clicking a point still switches it between sharp and smooth.
- **Deleting curve points keeps the shape.** The points either side stretch their handles across the gap, so the curve stays as near as it can (deleting a point you just added gives the curve back).
- **Handle types for curve points:** **Sharp** (a corner), **Smooth** (handles in line), **Broken** (each handle on its own, for a kink with curved sides) and **Auto** (handles that shape themselves from the neighbouring points). Set them under **Curve points → Handle type** in the Attributes panel, the E menu or **Mesh → Curve**.
- **Joining curves.** In the Points mode, select two end points and press **M** to weld them into one at their middle, or **A** to join them with a straight stretch: on one curve this closes it, on two curves it makes them one. **Join objects** on curves joins them end to end at their nearest ends.
- **Carrying a curve on.** With a curve selected, pick **Draw curve** and click one of its ends first: the points you draw are added to that curve, from either end, as one undo step; clicking its other end closes it.
- **Split, reverse, open or close a curve,** in the E menu (Points mode), **Mesh → Curve** and command search.
- **Round corners:** turn a curve's sharp points into smooth arcs of a radius you set in the Attributes panel, cut back to what fits.
- **Even spacing:** spread a curve's points evenly along it, as many as you like, keeping its shape.
- **Booleans: Union, Subtract and Intersect.** Select the shape to keep, Ctrl + click the shapes to cut it with, and choose **Mesh → Booleans**, a button on the modifiers palette beside the viewport, or press Space and type the name. The cutters stay shapes of their own, drawn as see-through outlines: move, turn, scale or edit one and the cut follows at once. Hidden cutters still cut. The Attributes panel lists a shape's booleans, so you can change Subtract to Union, take a cutter out or remove the boolean, and tells a cutter what it cuts. **Bake into shape** makes the cut permanent and hides the cutters. The result is tidy polygons with the UVs, materials and crisp edges of the shapes it came from; exports carry the cut shape and leave the cutters out. Shapes with holes in their surface can't be cut: the shape stays whole and the Attributes panel says which one is open.
- **The app remembers the order you select things in,** so for a boolean the shape you picked first is the one kept, whatever the Objects panel's order.
- **Loop cuts dead centre.** With one cut, hold Ctrl while pointing at an edge: the loop snaps to tenths of the edge, and the fifth is exactly the middle. It works while dragging too.
- **An emergency copy when the app crashes.** If the app ever stops with an error, it now saves your unsaved work as it was a moment before, as one last backup copy, and offers it back the next time it starts, so a crash costs seconds of work instead of up to the five minutes since the last backup.
- **Eleven new shapes.** **Create** now also makes an **Icosphere** (a ball of even triangles, no poles), **Torus**, **Capsule**, **Dome**, **Pipe elbow** (solid or hollow, any angle), **Pie sector**, **Gear**, **Hex grid**, **Hex sphere**, **Stairs** and **Arch**. **B** still lists the seven basic shapes; **Alt + B** lists the eleven new ones (once a list is open, B moves through it), so no shape is in both lists, and the Create menu has a line between the two groups. Each comes with its settings in the Attributes panel, ready-made UVs and seams, and crisp edges where it should have them, and is saved with the project like the others.
- **Weld polygons.** In the Polygons mode, **M** melts a selected polygon's points into one at its middle (each touching group of selected polygons at its own middle), and **Ctrl + M** lets you drag a polygon onto a point. Inset a cylinder's cap, then weld the middle polygon, and the cap becomes even triangles round one point.
- **Extrude from points.** In the Points mode, select points along an open edge (a plane's rim, or a hole's) and press **D**: the edges between them grow new polygons, and the new points are selected so you can carry on, or move them with W. If the points (or, in the Edges mode, the edges) go all the way round a polygon, such as a closed cap's rim, that polygon is pushed out instead. Handy in a side or front view, where points are easier to pick than edges.
- **Apply mirror.** Like Blender's Apply on a mirror: **Symmetry menu → Apply mirror** (also **Mesh → Shape and object** and command search) makes the mirrored half a real part of the shape and turns symmetry off, so each half can then be changed on its own. One undo step brings the mirror back.
- **Command search (Space).** Press **Space** (or the search button on the palette, or **Help → Search for a command**), type part of a command's name, and press Enter to run it. Each result says which menu it lives in and its key, if it has one.
- **Help menu.** **Help → User manual** opens this manual, **Words used in the app** explains the terms, and the heavy test shape moved to **Help → Developer**.
- **The UV menu in the UV Editor, and a UV settings panel** ([#115](https://github.com/Rhyslos/Aventail-3D/issues/115)). The UV Editor's menu line starts with a **UV** button holding the whole UV menu, and the UV Edit layout has a **UV settings** panel beside Attributes with every automatic UV tool's settings.
- **Solis in Made for, and your last export remembered.** File → Export…'s **Made for** list has **Solis**, the game engine made beside this app (glTF, metres, Y up, triangles, each object keeping its own name), and a game project folder inside a Solis project (one with a `project.solis` file) is recognised like Godot's. The app now remembers your last export's Made for and file settings, also after closing it, so new projects export the same way without setting it up again. Godot is still where it starts the first time.
- **Select connected (Alt + A).** Select a little of a part (a polygon, an edge, a point, or a piece in the UV mode) and press **Alt + A**, or choose **Select → Select connected** or **UV → Pieces → Select connected**: everything joined to it on the model is selected, across seams, and nothing of the shape's other parts.
- **Warning for pieces outside the UV square.** The UV Editor now also tints pieces sticking out of the texture square amber and counts them top right ("1 piece outside the square"). Trim sheet pieces are left out, as they run past the sides on purpose.
- **"Why is this here?"** Tick **View → Explain choices** in the UV Editor and point at a seam or a piece. A seam says why it's there (a hard edge, a sharp corner, a cut so a closed piece can lie flat, an edge you preferred, a stretch budget slit, or made by hand) and how to change it. A piece says what decides its size and place (locked, on a trim row, pinned, its own settings, its texel density against the aim and why) and what's wrong with it, each with what to do. Nothing changes until you act.
- **Seeing and checking UVs.** The UV Editor now always tints overlapping pieces red and mirrored pieces purple, and says top right how many there are (pieces stacked on purpose and trim pieces aren't counted). **View → Numbers on pieces** writes each piece's size in texture pixels, its texel density and, if uneven, how stretched it is. **View → Measure**, then drag, measures a line in texture pixels and in real centimetres on the surface; Esc stops.
- **Layout snapshots.** The UV Editor has a new **Snapshots** menu. **Take a snapshot** keeps the UVs and seams of the objects shown under a name you can change. Later, **Restore** puts them back in one undoable step (polygons made since keep theirs), **Compare** draws the snapshot faintly under the current UVs to see what changed, **Update** replaces it with the current layout, and **×** removes it. Snapshots are saved with the project. Projects move to file format 38.
- **A tidier UV menu.** The **UV** menu on the menu bar is now short and grouped: **Seams**, **Turn and flip**, **Lay out** (unwrap, relax, straighten, pack, texel density, trim rows), **Pieces** (pins, locks, piece settings, stretch budgets), then Texture, Trim sheet and Check for baking, and **Settings** for every automatic tool. Point at a group to see what's in it.
- **Locked pieces and piece settings.** **UV → Pieces → Lock pieces** keeps the selected pieces exactly as they are: Unwrap, Relax, Straighten, Pack, texel density, trim rows, Suggest seams and the fixing of UVs after modelling edits all leave them alone (they show faint stripes in the UV Editor). You can still move them by hand. **UV → Pieces → Piece settings** gives pieces their own method, straightening and texel density, used by every later unwrap of them. Projects move to file format 37.
- **Seam preferences and stretch budgets.** Select edges (or polygons) and choose **UV → Seams → Never seams here** to keep Suggest seams, Unwrap and Seams from hard edges from cutting there (blue), or **Prefer seams here** for where cuts should go first (pale orange). **UV → Pieces → Stretch budget** gives the selected pieces a budget, say 1.5×, and **UV → Settings → Seam suggestions** has one for every piece. A piece stretching more than its budget once laid flat gets cut further, a slit at a time, from where it's most squeezed to its edge, hidden as well as can be. Projects move to file format 36.
- **Every automatic UV tool fully under your control.** **UV → Settings** holds a submenu for each: **Seam suggestions** (how sharp a corner gets a seam, whether hard edges do, and where cuts hide), **Unwrapping** (the method, straight strips and how square they must be, unwrapping as seams change), **Relaxing** (how strong), **Packing** (now with a Fast, Standard or Best fit) and **Mending** (whether modelling edits fix the UVs they break, and how broken counts; saved with the project). Nothing is random: the same model and settings always give exactly the same UVs, and each edit keeps the settings it was made with. The unwrap switches and method moved into **UV → Settings → Unwrapping**. Projects move to file format 35.
- **Pins and unwrap methods.** Select UVs and choose **Pin** (E over the UV Editor, or the UV menu): they show as magenta dots, Unwrap lays the rest of the piece out around them, and Relax leaves them alone. **Unpin** frees them. **UV → Settings → Unwrapping** chooses how pieces are laid flat: **Keep shapes** (as before), **Keep shapes, smoother** (less size drift on curved pieces), **Keep sizes** (pixels the same size all over) or **Automatic** (each piece gets whichever lies most evenly, the same every time). **UV → Lay out → Unfold across only** and **Unfold up only** unwrap one way, keeping every point's height (or place across). In the E menu over the UV Editor, the four turns and flips now share one place, **Turn & flip**: choose it and they open right there. Projects move to file format 34.
- **Numbered checker.** A new choice under **Display → Surface**: a checker of cells labelled A1 to H8 laid on your shapes by their UVs, in a gradient of colours from your accent colour. Read a label on the model to find the piece in the UV Editor, which shows the same cells behind the UVs. A label that reads backwards means a mirrored piece.
- **Trim sheets.** Make the rows of a shared trim texture in the UV Editor's new **Trim** menu (names, and where each starts and how tall it is, in pixels; or 2, 4, 8 or 16 even rows), and see them as bands across the texture square. **UV → Lay out → Put on trim row** lays the selected strips straight along a row, filling its height, from its left end. Slide them along with W. Pack leaves trim pieces where they are, and Check for baking knows they repeat and overlap on purpose. It reminds you to give them a material of their own. Projects move to file format 33.
- **Check for baking looks at UVs.** **File → Check for baking…** (now also in the **UV** menu) lists what in your UVs would spoil a bake, and fixes most of it in one click: a shape with no UVs, hard edges that aren't UV seams, pieces folded over or squashed, pieces outside the texture square, lying over each other or closer than the padding, and pieces with much more or less texture than the rest. Objects that share a texture (the same material) are checked together, as Pack arranges them. When the list is empty, the UVs are ready to bake.
- **UVs survive modelling.** Extrude, bevel, inset, fill holes and the other modelling tools now give the polygons they make UVs that fit at once, carrying on from the polygons around them, so a piece you placed or turned by hand stays as it was. An extrude's walls become a straight new strip at the same texel density. Bevelling an edge that is a seam keeps the seam. And changing an earlier edit, or a cube's segments, makes your UV work again on the new shape. Model and UV in any order.
- **Edit UVs on the model.** In the UV mode, press **W**, **R** or **S** and drag in the viewport: the texture slides, turns or grows right on the shape, following the mouse (turn on **Display → Checker** to see it). A press on a piece that isn't selected selects it first; Shift makes it finer, Esc cancels, and each drag is one undo step. The piece under the mouse lights up in both the viewport and the UV Editor.
- **Checker and Stretch views.** The viewport's **Display** menu has a new **Surface** choice: **Checker** lays a checker on your shapes by their UVs (tinted so turned or mirrored pieces stand out), and **Stretch** colours them green where the UVs lie evenly, through yellow to red where they stretch or get too much or too little texture, purple where there's no room. The UV Editor colours its polygons the same way, and pointing at one says what's wrong and how to fix it.
- **Pack.** **E → Pack** over the UV Editor (or **UV → Lay out → Pack**) fits every piece into the texture square as large as it can go, all at the same scale, with a gap of real texture pixels between them. Pieces are fitted by their shapes, so small ones tuck into the gaps of big ones. **UV → Settings → Packing** sets the padding and whether pieces may turn, whether identical pieces share pixels, and whether each material (or object) gets a texture of its own.
- **Texture size and texel density.** Tell the app the texture size your UVs are for and the sharpness you aim for (pixels per metre) in the UV Editor's new **Texture** menu; they're saved with the project. The editor shows the texel density of what's selected against the aim, and **UV → Lay out → Set texel density** and **Match texel density** scale pieces to the aim or to one shared density. Zoom right in and the texture's pixels show.
- **Unwrap, Relax and Straighten.** Marking seams now lays the pieces around them flat at once (switch it off in the UV menu if you'd rather unwrap yourself), and **Unwrap** (E over the UV Editor, or the UV menu) does it on demand. Every piece keeps its real size against the others, lines up with the square and stays where it was; strips of square quads, like a cylinder's side, come out perfectly straight. **Relax** evens out stretched or hand-pulled UVs, and **Straighten** lays a piece of quads out as a straight grid. A piece that can't lie flat (a tube with no seam along it) is cut open where it shows least.

### Fixed

- **Changing settings for your next extrude no longer changes the last one.** Right after an extrude (or inset, bevel, loop cut and the other tools with settings), the Attributes panel and **Ctrl + wheel** still change it. Once you select something else, they set the tool for its next use instead, and the earlier edit stays as it is. To change it after all, click **Change it** beside "Last edit" in the panel, or open it from the edit list.
- **Extrudes, insets and bevels keep their shape on a stretched object too.** On an object scaled more along one axis than another, an inset's border and a bevel's width are now even all round as you see them, and "Straight out" goes straight out from the surface you see. Older edits are fixed by changing any of their settings. Projects move to file format 22.
- Changing a finished extrude's bend **Angle** from 0 no longer makes the Attributes panel jump: the extrude's Direction, End size, Steps and Flat end rows stay in place, greyed out, instead of disappearing.
- **A bend no longer stretches the pipe on a stretched object.** On an object scaled more along one axis than another, a bent extrude used to widen as it turned and end in an oval; it now keeps the pipe's shape as you see it. Older bends are fixed by changing any of their settings. Projects move to file format 21.
- Bending several polygons with **Keep together** off no longer grows and pulls most of them out of shape: each keeps its own size.
- Double-clicking to select a loop works every time with the Move, Rotate and Scale tools on. Before, the first click moved the gizmo under the mouse and the second click landed on it instead.
- After dissolving an edge, its red selected line and its cyan hard-edge mark no longer stay behind.
- Bent polygons and polygons with a dent are drawn (and picked) correctly, cut along lines inside them instead of a wrong triangle and a gap.
- Picking Inset after an extrude no longer shows the extrude's bend rows as if they were Inset's.
- **Damaged or booby-trapped project files can't crash or freeze the app.** Opening a file now checks, while reading, that it doesn't ask for more than the app can handle (memory, objects, edits, polygons), and explains when it does. A file of a few kilobytes that would unpack to gigabytes is refused at once.
- An edit that would make a shape impossibly large (over 30 million polygons) is skipped with a warning in the Attributes panel, instead of freezing the app.
- After a crash, a backup copy that closed the app while being restored isn't offered again, so you can't get stuck restoring it over and over. The question says when a copy was left out.
- Backup copies are kept in folders only you can read (on macOS and Linux), and two copies of the app starting at the same moment no longer mistake each other's backups for leftovers.
- A project whose file name starts with `-` can be opened from the command line by putting `--` before it.
- Undo's memory use is counted more truthfully, including the extra data the app keeps about how each shape's parts connect, so the history stays within its budget on huge shapes.
- **A project can no longer be saved in a state the app can't open again.** Every save and backup copy is now checked to open before it replaces the previous one; if it wouldn't, the save stops with a message and your previous save stays as it was. Two ways this could happen were found and fixed: bevelling two polygons back to back, and moving points of a shape whose size was set to 0 (a size of 0 in the Coordinates panel is now ignored).
- Saving no longer writes through links placed beside a project, so a project folder from a zip or download can't make Save overwrite another file.
- Opening a project with a damaged hard edge (which only affects shading) now leaves that edge out instead of refusing the whole project.
