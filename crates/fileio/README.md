# fileio

**Layer 2 · Services**

Everything that touches files: `.avtl` projects, OBJ and glTF import and export, the settings file.

## Purpose

Reads and writes the outside world's files: the versioned `.avtl` project format (DESIGN.md §8, decisions [0007](../../docs/decisions/0007-rhy-project-format.md) and [0010](../../docs/decisions/0010-avtl-file-extension.md)), OBJ and glTF for Substance Painter and Godot (with deterministic triangulation and MikkTSpace tangents), and the settings file described by `config`.

## Must never

- Trust a file: every reader checks sizes and counts before allocating, rejects bad input with a plain-language error, and gets a fuzz test
- Leave a half-written file: write to a temporary file, keep the previous save as a backup, then swap it in
- Write usernames or local paths into exported files
- Know about the GPU or UI

## Depends on

`scene`, `mesh`, `paint` (texture sets to save), `words` (the language layer: errors and warnings a person reads go through it, [decision 0134](../../docs/decisions/0134-shared-language-crate.md)); `uv` and `config` planned. Outside libraries: `serde`, `postcard` and `ciborium` (encoding), `zstd` (compression), `glam`, `image` (reading pictures as paint layers).

## Status

- **Painting** ([decision 0178](../../docs/decisions/0178-textures-on-materials.md)): project format 65 (`project/v65.rs`, decision 0179) adds each layer's strokes (`LayerV64::strokes`: kind, colour, hardness, flow, through and seven numbers a dab, checked on opening). Project format 64 (`project/v64.rs`) saves the texture sets (`ProjectV43::paint`: each set's layers and their painted tiles as byte blocks read with `deserialize_byte_buf`, each paid for from the read budget, checked on opening). `image_file::read_image` and `open_image` read PNG, JPEG, TGA and BMP through the `image` crate (`MAX_SIDE` 16384, TGA tried when nothing else matches), with plain-word errors and a small fuzz test.

**Projects** (`project`, decisions [0024](../../docs/decisions/0024-saving-projects.md) and [0031](../../docs/decisions/0031-project-format-version-2.md)):

- `to_bytes`/`from_bytes` and `save`/`open`. The file is a 20-byte header (`SIGNATURE` `AVTL`, `FORMAT_VERSION` 63, flags with bit 0 for zstd, the body's length) followed by the body: the file model (plain data separate from the scene's types) encoded with postcard and compressed with zstd. `project/v1.rs` holds the structures, generic over recorded operations (`ProjectFile<Op>`, `FileOperation`); version 1 uses `OperationV1` (moves), version 2 (`project/v2.rs`) `OperationV2` (moves, and points turned or scaled by a matrix, each with its anchors, `AnchorsV2`, every number checked on reading; [decision 0032](../../docs/decisions/0032-edits-find-their-points-again.md)). Version 3 (`project/v3.rs`, [decision 0038](../../docs/decisions/0038-extrude-and-inset.md)) stores version 2's operations as they were (`OperationV3::V2`), then extruded and inset polygons and extruded edges (distance checked, grouping, anchors; an edge must join two different points). Version 4 (`project/v4.rs`, [decision 0040](../../docs/decisions/0040-bevel.md)) wraps version 3's operations (`OperationV4::V3`) and adds bevelled edges and points (width and profile checked, rows brought within 1–64, profile within -1–1). **Backup copies** (`autosave`, [decision 0036](../../docs/decisions/0036-autosave.md)):

- `Session::start` makes a `session-<time>-<process>-<n>` folder inside the autosave folder and keeps its `lock` file locked (`File::try_lock`) while the app runs; the system lets go of the lock when the process ends in any way, a crash included.
- `Session::set_project` notes the open project in `project.txt`. `write`/`write_copy_in` write `copy-N.avtl` (written beside its name, synced, then renamed) and delete the oldest beyond the number kept (at least one). `adopt` copies a restored copy into the new session, keeping its time. `end` deletes the folder (a normal close).
- `leftovers` lists the sessions whose lock can be taken (no longer running) with their copies, newest first, and tidies away dead sessions without copies; `discard` deletes one. A session folder without its lock file is left alone for its first minute (an app may be starting). Backup folders are made readable only by their owner on Linux and macOS.
- `write_emergency_in` writes the *emergency copy* (the app's panic hook calls it): the next `copy-N.avtl`, deleting no older copy, and `emergency.txt` naming it; `leftovers` marks that copy `Copy::emergency`, so recovery can say what it was. A note naming a copy that's gone is ignored.
- `mark_restoring` notes in a leftover's folder which copy is being restored, and `clear_restoring` removes the note once the restore finishes; a note still there at the next start leaves that copy out (`Leftover::left_out`), so a copy whose restore closed the app isn't offered again (decision 0045).

Tests: numbering and keeping the newest, a running session versus a crashed one, order and the untitled case, tidying and ignoring other files, adopting (with its time) and two sessions side by side, the emergency copy (newest, nothing deleted, marked; a stale note; no folder).

**Collision in parts in exports** (`export/collision.rs`, [decision 0151](../../docs/decisions/0151-collision-hulls.md)): with `godot_names`, an object whose collision is `Collision::Parts` carries its parts' hulls (`ExportedObject::collision_parts`, worked out from its exported shape by `Scene::collision_shapes`, placed around its pivot in the file's axes and units, flat normals); `write_glb` writes each as a node of its own beside it, `name-part1-convcolonly` and on (`part_objects`), at its pivot, as *A box*'s `name-convcolonly`. Tested for names, counts, corners and pivots in `gltf/tests.rs`.

**Levels of detail in exports** (`export/lods.rs`, `export/lods_tests.rs`, [decision 0155](../../docs/decisions/0155-levels-of-detail.md)): with `ExportOptions::lod_levels`, an object with levels of detail carries them (`ExportedObject::levels`, `ExportLevel`: each level's real shape from `Scene::lod_shapes`, with its modifier changes, reduced or made by hand (decision 0165), placed and shaded as the object, distances in the file's units). `level_objects` makes each an object of its own, `name_LOD1` and on, with its `LevelMark` (level, begin, end); `write_glb` writes them as nodes beside it with `extras` `{ lod_level, lod_begin, lod_end }` (the object's own node too, as level 0), hidden for Godot (`KHR_node_visibility`, in `extensionsUsed`); `write_files` adds them to an OBJ as objects after the others. The summary counts the objects only; a hand-made level's own shape is never exported as an object (`Scene::is_level_shape`). Godot reads no hand-made levels (it makes its own on import); `tools/gltf-check/lod_ranges.gd` turns these into visibility ranges, and the Godot import check runs it on `godot-lods.glb`.
