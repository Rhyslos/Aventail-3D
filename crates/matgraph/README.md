# matgraph

**Layer 1 · Core**

Material graphs: boxes joined by wires, worked out into seamless textures.

## Purpose

The engine behind the Material mode (Phase 12, [decision 0256](../../docs/decisions/0256-material-graph-plan.md), [decision 0257](../../docs/decisions/0257-material-graphs-core.md), the plan in [docs/plans/phase-12.md](../../docs/plans/phase-12.md)): what a graph is, every change to it, and working it out into pictures. Everything here can be tested without a window or a GPU.

## Must never

- Know about scenes, undo, files, the GPU or UI (the scene keeps graphs and records their edits; `fileio` saves them; the interface draws them)
- Change a graph except through a checked `GraphEdit`, or refuse one without a reason in plain words
- Make a texture that doesn't tile, or that changes with the number of cores
- Allocate a picture outside `Size::MIN` to `Size::MAX`, or panic on a damaged graph

## Depends on

`words` (the language layer: every reason, name and note goes through it), `glam`, `shapes` (the Shape box's drawings, layer 1).

## Status

Phase 12, milestone 1 (the core), milestone 3 (the first boxes), milestone 4 (the seam check), milestone 5 (graphs in the painter), milestone 6 (baked export), milestone 7 (your own boxes), milestone 8b (boxes on any kind), milestone 9 (Scatter), milestone 10 (more boxes), milestone 14 (foliage output), milestone 15 (animated boxes) and milestone 16 (bypass and reroute dots):

- **Value kinds** (`kind`): `ValueKind` (shape, height, colour, whole material; `name`, `described`), `fit(from, to)`: `Fit::Fits`, `Fit::Converts(note)` (a shape as a height, greys as a colour, a material's height or colour) or the reason it can't ("a colour has no inside or outside").
- **Pictures** (`image`, `value`): `Image<P>` (square, row 0 the top; `at` wraps round past every edge, `sample` blends and wraps), `Grey` and `Rgb` (sRGB 0 to 1, or normals), `Size` (a power of two, 16 to 4096; `new` refuses others with the reason and the nearest size as a fix; `nearest`; `PREVIEW` 256). `Value` (`Shape`, `Height`, `Colour`, `Material`, each shared in an `Arc`; `converted`), `MaterialMaps` (colour, height, roughness, metal, normal (OpenGL, y up the texture), occlusion, curvature, and optional opacity and translucency for alpha cards: `None` solid, no light through; `opacity_at`, `is_cut_out`).
- **Refusals** (`refusal`): `Refusal { reason, fixes }`; `Fix` (put a box between, add a box, connect another output instead, use a size, use the nearest value, look at a box, remove a box; `describe` words it as a choice). Nothing changes until a fix is picked, which the interface does (milestone 2).
- **Kinds of box** (`registry`): `BoxType` (`info`, `run`), `BoxInfo` (id saved in files, plain name, `Group` (Make, Shape, Detail, Colour, Material, listed as "Finish": the experts' working order), "What does this do?", input and output `PlugSpec`s (key, name, kind, needed), `SettingSpec`s, "usually comes next", one per graph), `Label` (an English key through `words`, or a person's own words for boxes they make, milestone 7), `Job` (size, seed, cores, settings by key, inputs converted to each plug's kind; `fill_grey`, `fill_rgb`, `map_grey`), `Registry` (`standard()` made once, `with_standard_boxes`, `add` refuses a taken id, `iter` by group).
- **Settings** (`settings`): `SettingKind` (number, whole number, colour, choice, switch, seed), `SettingValue`, `SettingSpec::check` (out of range says so, offering the nearest), `nearest`; `Settings` keeps changed values by key (`resolved`, `normalised`), so kinds can gain settings and old graphs still read.
- **Graphs** (`graph`): `Graph` (name, seed, `GraphBox`es by `BoxId`, `Wire`s between `PlugRef`s, one per input, comment `Frame`s by `FrameId` with title, colour, rectangle and note; ids from one counter, never reused). `GraphEdit` (add, remove, dissolve (keeping the wire through), move, set a setting, connect, disconnect, add, change and remove frames, seed, rename; `describe` for undo) through `Graph::apply`, all checked. `check_connection` says how a wire fits or why not, with fixes (boxes that could go between (not those only passing the wanted kind on), other outputs that fit, nearest first); loops and a box feeding itself are refused. `order` (each box after what feeds it), `feeds`, `boxes_in(frame)`, `to_parts` / `from_parts` (everything checked, settings kept in range, kinds from a newer app kept as they are). Limits: `MAX_BOXES`, `MAX_FRAMES`, `MAX_NAME`, `MAX_NOTE`.
- **Working out** (`eval`, `cache`, `parallel`): `Evaluator::run(registry, graph, size, wanted)` gives an `Evaluation` (each box's `BoxResult` (outputs and its picture) or the `Refusal` saying why it can't run: an empty needed input, a box it waits for, a kind from a newer app; `made`, `reused`, `problems`); `material` gives the Material out box's material. Each box's result is kept in the `Cache` under a hash of its kind, settings, size, seed and its inputs' keys, so only what changed is worked out again; results the last run didn't use are forgotten past the budget (512 MB standard). Each box's pixels are shared over the cores in bands of 64 rows (`std::thread::scope`), so the result is the same on any number of cores.
- **Painted-in light** (`light`, milestone 10): `sun`, `lit` (light to shade by how a surface faces the sun, with softness) and `warmed`: the painter's light and shade helper (`paint::Lighting`) calls them, as the Directional light box does, so both light alike.
- **The Shape box** (`boxes::drawn_shape`, milestone 11, [decision 0273](../../docs/decisions/0273-shape-canvas.md)): a box drawn on the shape canvas. `GraphBox::drawing` (a `shapes::Drawing`, kept only by a kind whose `BoxType::takes_drawing` says so; dropped from others by `from_parts`), changed only by `GraphEdit::SetDrawing` (checked again with `Drawing::from_parts`); `Job::drawing`; the drawing's `key` (not its reference image) is part of the box's cache key. Outputs **Mask** (`shapes::raster::mask`), **Height** (rising with `distance_inside` up to Puff, round) and **Outline** (a band along the edge, in and out, with the lines); `drawn` (pub, for the canvas's strip). `GraphBox::copy_edits` gives a box's settings and drawing as edits, for pasting and opening your own box back up. Milestone 12 ([decision 0274](../../docs/decisions/0274-assemblies.md)): a fourth output, **Colours** (each piece's colour laid in order over black), and the Height times each piece's own height (`shapes::raster::layers`); `drawn` returns `Drawn`. Tests in `drawn_shape.rs`.
- **Edges, varied copies and veins** (milestone 13, [decision 0275](../../docs/decisions/0275-edges-and-variation.md)): the drawing's paths already carry edges and varying (`shapes::Drawing::drawn_paths`); `drawn` adds `shapes::raster::veins` to the Height (times the mask and the box's Height) and darkens or lightens the Colours along them, only where the shape is. Tests: veins in the height and colours, toothed and varied shapes tiling (and moved half a texture coming out the same, rolled).
- **Alpha cards** (milestone 14, [decision 0276](../../docs/decisions/0276-foliage-output.md)): the **Opacity** box (`boxes::opacity`, Finish): a material, an Opacity shape and an optional Thickness in; the material out with its opacity, its translucency (Translucency × opacity × (1 − Thick parts block light × thickness); none at 0) and its colour bled out under the cut-away parts (`bled`, a pull-push). Boxes handing a material on keep the two maps (Transform, Repeat, Slope blur, Fill the gaps, `Value::repeated`); Mix materials mixes them (`either`: a missing opacity solid, a missing translucency none); Scatter makes the gaps between see-through copies see-through. The Shape box's **Layout → Leaf sheet** (`layout`, `gap`, `turn`; `drawn_on`) lays the drawing out with `shapes::Sheet`. The seam check judges an alpha card's colour where it is solid, and its opacity. Tests in `boxes/opacity.rs`, `drawn_shape.rs` (a leaf sheet inside the texture) and `seams.rs`.
- **Animated boxes** (milestone 15, [decision 0277](../../docs/decisions/0277-animated-boxes.md)): `Job::time` / `with_time` (seconds, 0 to `MAX_MOMENT`), given to every job by the evaluator: `Evaluator::set_time` (the preview's player) or, with none set, the graph's own `Graph::moment` (what exports and the painter bake; `GraphEdit::SetMoment`); `Given::time` runs an own box's inside at the outer moment. Boxes with `BoxInfo::animated` hash the moment and the real-world size into their cache key, so boxes they don't feed are reused as the time goes on. The **Moving** group (`Group::Move`): **Time** (`time`: Loop and Wave flat greys over Period), **Scroll** (`scroll`: moves any kind by Direction and Speed in cm a second; Loops rounds the slide to whole textures per Loop length), **Pulse** (`pulse`: a height, a colour or a material's colour times Lowest to Highest, Rate a second, Smooth / Sharp / Steps; the strength as a grey with nothing plugged in), **Flow** (`flow`: any kind dragged along a flow map, downhill on a height or in Direction, two copies half a Stretch time apart blended |1 − 2·phase| so restarts never show); shared parts in `boxes::motion` (`Wave`, `through`, `heading`, `mixed`). `Graph::is_animated`. **Change in the game:** `GraphBox::in_game` (setting keys, copied by `copy_edits`), `GraphEdit::ChangeInGame` (numbers, lengths, whole numbers, colours and switches only: `changes_in_game`), `Graph::in_game`; `bake_notes` gives `BakeNote::Animated` (with the moment, `baking::seconds`) and `BakeNote::InGame`. Tests in each box's file (seamless at every moment, determinism, pulse range, flow continuity through its restarts, loops), `eval/time_tests.rs` (same moment same material on any cores, the cache across moments, the graph's moment, real-world size, own boxes) and `graph/tests.rs` (marks and the moment, through parts).
- **Bypass and reroute dots** (milestone 16, [decision 0278](../../docs/decisions/0278-bypass-and-reroute-dots.md)): `GraphBox::bypassed`, `GraphEdit::Bypass` (refused for a box with no outputs), copied by `copy_edits`. The evaluator doesn't run a bypassed box (`eval/bypass.rs`): `passed_through(inputs, outputs, plugged)` gives each output the first plugged input of its kind, else the first converting (pub, for the canvas's wire through the box); an output with none is empty and the boxes after it refuse with `bypass::nothing_passed` (plain words, `Fix::StopBypass` and `Fix::LookAt`); a needed input left empty doesn't refuse. Its key hashes only its kind, the size and its inputs' keys (no settings, seed, drawing, model or time), and nothing is put in the cache for it. `Graph::is_animated`, `OwnBox::info` and `bake_notes` leave bypassed boxes out of moving; `BakeNote::Bypassed` lists them. **Reroute dots** (`graph/bends.rs`): `Graph::bends(to)`, `all_bends`, `GraphEdit::SetBends { to, points }` (at most `MAX_BENDS` 16, real places, a wire into `to`), dropped with their wire (disconnected, replaced from another output, dissolved, a box removed), moved by `MoveBoxes` when both ends move; `GraphParts::bends` (a wire not there: dropped; too many or not real: damaged). Own boxes keep inner wires' dots when made and opened up. Tests in `eval/bypass_tests.rs` (each kind passed, conversion, refusals, waiting, the cache while playing, switching back and forth, inside an own box), `eval/bypass.rs`, `graph/bend_tests.rs` (edits, refusals, dots following their wire and boxes, parts, a fuzz run) and `baking.rs`.
- **Seeds** (`seed`): `mix`, `box_seed` (the box's Seed setting mixed with the graph's), `unit`, `lattice`: patterns come from hashing, never a clock.
- **The boxes** (`boxes`, milestones 1, 3 and 5, [decision 0259](../../docs/decisions/0259-first-material-boxes.md)), one file each, listed in `boxes::standard` in the working order:
  - **Make:** Noise (layered gradient noise on a wrapping lattice), Clouds (layered value noise: soft, billowy, ridged), Cells (cellular pattern: distance, bumps, edges, flat; Random per cell), Gradient (up and down, ramp, round; across, down, diagonal), Bricks (rows made even, mortar even all round; Random), Tiles (with a shift; Random and a Seed added in milestone 3), Planks (random board ends; Random; Grain), Basic shape (circle, square, polygon, star by signed distance, joined with neighbouring repeats).
  - **Shape:** Blur (`blur_box.rs`), Warp (by a height's slope, or its own noise), Slope blur (`slope_blur.rs`, milestone 10: a height, a colour or a material smeared along By's slope or its own noise's, Smear, Wear down or Build up, as Transform takes any kind), Levels, Edge finder (`edges.rs`), Bevel (Round, Sharp, Steps; Roundness softens), Transform (moves, quarter turns, flips), Repeat, Blend (six modes, through an optional shape). Transform and Repeat take a height, a colour and a whole material (`moving.rs`, [decision 0270](../../docs/decisions/0270-tiling-and-moving-colours.md)): each plugged input moved the same way, a material's normals turned and steepened with it; `BoxType::run_outputs` leaves an output whose input is empty as `None` (`BoxResult::outputs` are `Option`s; a box wired to one is refused with why) and `BoxType::needs_an_input` makes the evaluator refuse one with nothing plugged in. Tests in `boxes/tests_moving.rs` (heights exactly as the old maths, every kind seamless and in range, normals, seeds and cores, the refusals).
  - **Detail:** Scatter (`scatter.rs`, `scatter/placing.rs`, milestone 9, [decision 0271](../../docs/decisions/0271-scatter.md)): copies of a shape (its greys their height), a colour or a whole material at random (one per Spacing squared) or in a grid (whole rows; Loose, Shift rows), each with its own size, turn, height, colour and grey (Random), placed on one core from the seed; Keep apart leaves out copies that would touch (wrapped distances, a cell grid); Where thins them by its grey at each copy's middle; round pebbles with nothing plugged in. Each pixel finds the copies near it through `placing::Lookup` (cells about a copy's reach wide, copies over an edge listed with their middles moved by whole textures); the highest copy is on top. Outputs: Material and Colour (only when plugged in), Height, Copies (where any copy is), Random. At most `MAX_COPIES` (16 384), never more than `MAX_DEPTH` (32) textures' worth of copy area. Tests in `scatter/tests.rs` and `placing.rs` (in range and seamless with every kind and many settings, seeds and cores, each variation, Where, centimetres, the ends of every setting, normals turning, the refusals, a pebbles graph end to end); `scatter_speed` (ignored) times it.
  - **More Detail** (milestone 10, [decision 0272](../../docs/decisions/0272-more-boxes.md)): Cracks (`cracks.rs`: a jittered grid's borders, wandering by noise, each cracked or not by its own number, exact distance to a border by the two-pass cell search), Chips (`chips.rs`: angular cells biting in from a shape's outline by `distance_inside`), Scratches (`scratches.rs`: tapering lines placed by `scatter::placing`), Fill the gaps (`fill_gaps.rs`: a height's low places filled up to a patchy level; the gaps, the filled height, and a colour or material with the filling laid in). Each wear box also gives its marks as a shape.
  - **More Colour** (milestone 10): Brush strokes (`brush_strokes.rs`: strokes placed by `scatter::placing`, each laying the colour under its middle, bristle streaks, later ones on top; a material's colour only), Edge highlight (`edge_highlight.rs`: the height less a soft blur of it: edges lightened, hollows darkened), Directional light (`directional_light.rs`: the painter's light and shade for a material through `light`, slopes from the height Depth deep, shadows looked for toward the sun). Tests in `boxes/tests_more.rs`; `more_box_speed` (ignored) times them.
  - **Colour:** Colour fill, Gradient map (a `ColourGradient` setting, looked up from a table of 1024), Hue and saturation (HSL; through an optional shape), Colour to shape (by lightness or closeness to a colour; the box offered between a colour and a shape plug).
  - **Finish:** Material from height (normal, occlusion and curvature from the height; colour, roughness and metal), Mix materials (by shape or by height; every map, normals made a unit long), Material out (the graph's result, with its real-world size; one per graph).
  - `pattern`: `soft_blur` (three box blurs), `distance_inside` (the exact distance to the nearest outside pixel, Felzenszwalb and Huttenlocher's transform on rows lengthened by wrapping), `cell_random` (a random number per wrapped cell). `blur::box_blur` wraps round.
- **Lengths and gradients** (`settings`, `registry`): `SettingKind::Length` (centimetres, a number), turned into pixels by `Job::length_px` with the graph's real-world size (`Job::with_real_size`; the evaluator reads Material out's with `eval::real_size_cm`, `STANDARD_REAL_SIZE_CM` without one, and hashes it only into boxes with a length, `BoxInfo::uses_real_size`). `SettingKind::Gradient` / `SettingValue::Gradient(ColourGradient)`: 2 to `MAX_STOPS` `GradientStop`s kept in the order added, read sorted (`colour_at`), `with_stop_added` (in the widest gap), `with_stop_removed`, `with_stop`, `clamped`.
- **The seam check** (`seams`, milestone 4, [decision 0260](../../docs/decisions/0260-preview-and-checks.md)): `SeamCheck::of(value)` compares the average step across each join (right edge to left, bottom to top) with the average step between neighbours elsewhere, for every channel (a material's colour, height and roughness); a `Join` shows when it jumps more than three times as much and more than about two levels in 255. `describe` says what it found in plain words. Not-a-number counts as a join that shows.
- **On a model** (`model`, milestone 5, [decision 0261](../../docs/decisions/0261-graphs-in-the-painter.md)): `ModelMap` (curvature, occlusion, thickness, facing up, up, across, front to back; `neutral`), `ModelMaps` (greys at one size, with a key for the cache), `OnModel` (the maps, the repeats across the texture square and the layer's Tiling (`new`, `with_tiling`; decision 0270: `repeats()` includes it, `square_cm` doesn't, so what follows the model keeps its size); `tile_size`, `square_cm`), `is_from_model`, `uses_model`, `maps_needed`, `Value::repeated` (a value laid `repeats` times across a bigger picture, blended, wrapping). `Evaluator::run_on_model` and `material_on_model`: boxes nothing from the model feeds make the repeat at `tile_size`; the From the model boxes and what they feed work on the model's square at its size, told it covers `square_cm`, taking repeats laid across it; a From the model box's key includes the maps' key. `Job::with_model` / `model_map`. The **From the model** boxes (`boxes::from_model`, `Group::Model`): Curvature (Curvature, Edges, Creases), Occlusion, Position (Up, Across, Front to back), Thickness, Facing up; a stand-in of rounded bumps (`stand_in`) without a model. **Shown in the painter:** `GraphBox::shown` (setting keys), `GraphEdit::ShowInPainter`, `Graph::shown` (`Shown`: box, kind, setting, value, in running order), `Graph::with_settings` (a copy with a layer's own values; refused ones left out). Tests in `model/tests.rs` and `graph/tests.rs`.
- **Baking** (`baking`, milestone 6, [decision 0262](../../docs/decisions/0262-baked-export.md)): `bake_notes(registry, graph, on_model)` gives `BakeNote`s (`Unknown` boxes from a newer app, which stop a bake; `Animated` boxes, baked at their current setting; `FollowsModel`, From the model boxes off a model, baked as their stand-in), each with `describe` in plain words and what to do. `BoxInfo::animated` marks milestone 15's moving boxes; `BakeNote::InGame` lists settings marked "change in the game".
- **Your own boxes** (`own`, milestone 7, [decision 0263](../../docs/decisions/0263-your-own-boxes.md)): `OwnBox` (id `own:` and hex, name and words in the maker's own words, a 48-pixel picture, the graph inside, `OwnInput`s feeding inner plugs, `OwnOutput`s from inner plugs, `OwnSlider`s for inner settings; `check`, `normalised`, `info` (a `BoxInfo` in `Group::Own`, its sliders as settings starting at the inner values), `inner_with`, `uses`, `to_parts` / `from_parts`), `OwnBoxType` (works its inside out with `Evaluator::run_given`: what is plugged in, the outer graph's seed and real-world size; refuses past `MAX_DEPTH`), `registry_with` and `add_own` (each own box after those inside it, so none runs itself), `Proposal` (`of` a selection: plugs from the wires crossing its edge, settings to choose sliders from; refusals for Material out, From the model boxes, a loop through a box outside, no output, too many plugs; `make`: the own box and the edits replacing the selection), `open_up` (the edits putting its boxes back), `fresh_id`, `picture_of`. `Evaluator::run_given` (`Given`), `Evaluator::run_inside` (the pictures inside a placed own box), `Evaluation::key`; `BoxType::version` and `own`; `Job::graph_seed`, `resolved_settings`. Making a box and opening it back up never change the picture. Tests in `own/tests.rs` (every subset of a graph made into a box and opened up again gives the same material).
- **Bringing own boxes from another project** (`own/bringing.rs`, [decision 0268](../../docs/decisions/0268-paste-between-tabs.md)): `bring_in` works out which of the boxes coming in the project already has the same of (reused), which need a new id because the project has another box with theirs, and gives them in order with the boxes inside renamed (`Brought`); `needed` lists the own boxes some boxes need, through every level; `rename_kinds`, `same_or_numbered`, `unused_name`.
- **Projects' graphs** (`store`): `GraphStore` (graphs by `GraphId`, each shared, ids never reused; `from_graphs` for files; `MAX_GRAPHS`; the project's own boxes, `own`, `put_own`, `with_own`, `users_of`, and its registry, `registry`, made again when an own box changes).
- Tests in each module and `graph/tests.rs`, `eval/tests.rs`, `boxes/tests.rs`: refusals and their fixes, loops, frames, damaged parts, a fuzz run of random edits, seamless tiling of every maker and of a made material, cache hits after each kind of change, seeds, the same result on 1 to 16 cores, empty and unknown boxes, the cache budget. `boxes/tests_each.rs`: every box's outputs in range, seamless tiling (standard and other settings), the same pictures for the same seed on any number of cores and others for another seed, every setting at its extremes with the smallest and largest real-world sizes, flat inputs, what each box does, the colour-to-shape fix, lengths following the real-world size (and only those boxes made again), and a stone-tiles graph end to end. `graph_speed` and `box_speed` (ignored) time a graph and the heavier boxes by hand.
