# matgraph

**Layer 1 · Core**

Material graphs: boxes joined by wires, worked out into seamless textures.

## Purpose

The engine behind the Material mode (Phase 12, [decision 0256](../../docs/decisions/0256-material-graph-plan.md), [decision 0257](../../docs/decisions/0257-material-graphs-core.md), the plan in [docs/plans/phase-12.md](../../docs/plans/phase-12.md)): what a graph is, every change to it, and working it out into pictures. Everything here can be tested without a window or a GPU.

## Must never

- Know about scenes, undo, files, the GPU or UI (the scene keeps graphs and records their edits; `fileio` saves them; the interface draws them)
- Change a graph except through a checked `GraphEdit`, or refuse one without a reason in plain words
- Make a texture that doesn't tile, or that changes with the number of cores
- Allocate a picture outside `Size::MIN` to `Size::MAX`, or panic on a damaged graph

## Depends on

`words` (the language layer: every reason, name and note goes through it), `glam`.

## Status

Phase 12, milestone 1 (the core), milestone 3 (the first boxes), milestone 4 (the seam check), milestone 5 (graphs in the painter) and milestone 6 (baked export):

- **Value kinds** (`kind`): `ValueKind` (shape, height, colour, whole material; `name`, `described`), `fit(from, to)`: `Fit::Fits`, `Fit::Converts(note)` (a shape as a height, greys as a colour, a material's height or colour) or the reason it can't ("a colour has no inside or outside").
- **Pictures** (`image`, `value`): `Image<P>` (square, row 0 the top; `at` wraps round past every edge, `sample` blends and wraps), `Grey` and `Rgb` (sRGB 0 to 1, or normals), `Size` (a power of two, 16 to 4096; `new` refuses others with the reason and the nearest size as a fix; `nearest`; `PREVIEW` 256). `Value` (`Shape`, `Height`, `Colour`, `Material`, each shared in an `Arc`; `converted`), `MaterialMaps` (colour, height, roughness, metal, normal (OpenGL, y up the texture), occlusion, curvature).
- **Refusals** (`refusal`): `Refusal { reason, fixes }`; `Fix` (put a box between, add a box, connect another output instead, use a size, use the nearest value, look at a box, remove a box; `describe` words it as a choice). Nothing changes until a fix is picked, which the interface does (milestone 2).
- **Kinds of box** (`registry`): `BoxType` (`info`, `run`), `BoxInfo` (id saved in files, plain name, `Group` (Make, Shape, Detail, Colour, Material, listed as "Finish": the experts' working order), "What does this do?", input and output `PlugSpec`s (key, name, kind, needed), `SettingSpec`s, "usually comes next", one per graph), `Label` (an English key through `words`, or a person's own words for boxes they make, milestone 7), `Job` (size, seed, cores, settings by key, inputs converted to each plug's kind; `fill_grey`, `fill_rgb`, `map_grey`), `Registry` (`standard()` made once, `with_standard_boxes`, `add` refuses a taken id, `iter` by group).
- **Settings** (`settings`): `SettingKind` (number, whole number, colour, choice, switch, seed), `SettingValue`, `SettingSpec::check` (out of range says so, offering the nearest), `nearest`; `Settings` keeps changed values by key (`resolved`, `normalised`), so kinds can gain settings and old graphs still read.
- **Graphs** (`graph`): `Graph` (name, seed, `GraphBox`es by `BoxId`, `Wire`s between `PlugRef`s, one per input, comment `Frame`s by `FrameId` with title, colour, rectangle and note; ids from one counter, never reused). `GraphEdit` (add, remove, dissolve (keeping the wire through), move, set a setting, connect, disconnect, add, change and remove frames, seed, rename; `describe` for undo) through `Graph::apply`, all checked. `check_connection` says how a wire fits or why not, with fixes (boxes that could go between, other outputs that fit, nearest first); loops and a box feeding itself are refused. `order` (each box after what feeds it), `feeds`, `boxes_in(frame)`, `to_parts` / `from_parts` (everything checked, settings kept in range, kinds from a newer app kept as they are). Limits: `MAX_BOXES`, `MAX_FRAMES`, `MAX_NAME`, `MAX_NOTE`.
- **Working out** (`eval`, `cache`, `parallel`): `Evaluator::run(registry, graph, size, wanted)` gives an `Evaluation` (each box's `BoxResult` (outputs and its picture) or the `Refusal` saying why it can't run: an empty needed input, a box it waits for, a kind from a newer app; `made`, `reused`, `problems`); `material` gives the Material out box's material. Each box's result is kept in the `Cache` under a hash of its kind, settings, size, seed and its inputs' keys, so only what changed is worked out again; results the last run didn't use are forgotten past the budget (512 MB standard). Each box's pixels are shared over the cores in bands of 64 rows (`std::thread::scope`), so the result is the same on any number of cores.
- **Seeds** (`seed`): `mix`, `box_seed` (the box's Seed setting mixed with the graph's), `unit`, `lattice`: patterns come from hashing, never a clock.
- **The boxes** (`boxes`, milestones 1, 3 and 5, [decision 0259](../../docs/decisions/0259-first-material-boxes.md)), one file each, listed in `boxes::standard` in the working order:
  - **Make:** Noise (layered gradient noise on a wrapping lattice), Clouds (layered value noise: soft, billowy, ridged), Cells (cellular pattern: distance, bumps, edges, flat; Random per cell), Gradient (up and down, ramp, round; across, down, diagonal), Bricks (rows made even, mortar even all round; Random), Tiles (with a shift; Random and a Seed added in milestone 3), Planks (random board ends; Random; Grain), Basic shape (circle, square, polygon, star by signed distance, joined with neighbouring repeats).
  - **Shape:** Blur (`blur_box.rs`), Warp (by a height's slope, or its own noise), Levels, Edge finder (`edges.rs`), Bevel (Round, Sharp, Steps; Roundness softens), Transform (moves, quarter turns, flips), Repeat, Blend (six modes, through an optional shape).
  - **Colour:** Colour fill, Gradient map (a `ColourGradient` setting, looked up from a table of 1024), Hue and saturation (HSL; through an optional shape), Colour to shape (by lightness or closeness to a colour; the box offered between a colour and a shape plug).
  - **Finish:** Material from height (normal, occlusion and curvature from the height; colour, roughness and metal), Mix materials (by shape or by height; every map, normals made a unit long), Material out (the graph's result, with its real-world size; one per graph).
  - `pattern`: `soft_blur` (three box blurs), `distance_inside` (the exact distance to the nearest outside pixel, Felzenszwalb and Huttenlocher's transform on rows lengthened by wrapping), `cell_random` (a random number per wrapped cell). `blur::box_blur` wraps round.
- **Lengths and gradients** (`settings`, `registry`): `SettingKind::Length` (centimetres, a number), turned into pixels by `Job::length_px` with the graph's real-world size (`Job::with_real_size`; the evaluator reads Material out's with `eval::real_size_cm`, `STANDARD_REAL_SIZE_CM` without one, and hashes it only into boxes with a length, `BoxInfo::uses_real_size`). `SettingKind::Gradient` / `SettingValue::Gradient(ColourGradient)`: 2 to `MAX_STOPS` `GradientStop`s kept in the order added, read sorted (`colour_at`), `with_stop_added` (in the widest gap), `with_stop_removed`, `with_stop`, `clamped`.
- **The seam check** (`seams`, milestone 4, [decision 0260](../../docs/decisions/0260-preview-and-checks.md)): `SeamCheck::of(value)` compares the average step across each join (right edge to left, bottom to top) with the average step between neighbours elsewhere, for every channel (a material's colour, height and roughness); a `Join` shows when it jumps more than three times as much and more than about two levels in 255. `describe` says what it found in plain words. Not-a-number counts as a join that shows.
- **On a model** (`model`, milestone 5, [decision 0261](../../docs/decisions/0261-graphs-in-the-painter.md)): `ModelMap` (curvature, occlusion, thickness, facing up, up, across, front to back; `neutral`), `ModelMaps` (greys at one size, with a key for the cache), `OnModel` (the maps and the repeats across the texture square; `tile_size`, `square_cm`), `is_from_model`, `uses_model`, `maps_needed`, `Value::repeated` (a value laid `repeats` times across a bigger picture, blended, wrapping). `Evaluator::run_on_model` and `material_on_model`: boxes nothing from the model feeds make the repeat at `tile_size`; the From the model boxes and what they feed work on the model's square at its size, told it covers `square_cm`, taking repeats laid across it; a From the model box's key includes the maps' key. `Job::with_model` / `model_map`. The **From the model** boxes (`boxes::from_model`, `Group::Model`): Curvature (Curvature, Edges, Creases), Occlusion, Position (Up, Across, Front to back), Thickness, Facing up; a stand-in of rounded bumps (`stand_in`) without a model. **Shown in the painter:** `GraphBox::shown` (setting keys), `GraphEdit::ShowInPainter`, `Graph::shown` (`Shown`: box, kind, setting, value, in running order), `Graph::with_settings` (a copy with a layer's own values; refused ones left out). Tests in `model/tests.rs` and `graph/tests.rs`.
- **Baking** (`baking`, milestone 6, [decision 0262](../../docs/decisions/0262-baked-export.md)): `bake_notes(registry, graph, on_model)` gives `BakeNote`s (`Unknown` boxes from a newer app, which stop a bake; `Animated` boxes, baked at their current setting; `FollowsModel`, From the model boxes off a model, baked as their stand-in), each with `describe` in plain words and what to do. `BoxInfo::animated` is the hook milestone 15's animated boxes set (false for every box so far).
- **Projects' graphs** (`store`): `GraphStore` (graphs by `GraphId`, each shared, ids never reused; `from_graphs` for files; `MAX_GRAPHS`).
- Tests in each module and `graph/tests.rs`, `eval/tests.rs`, `boxes/tests.rs`: refusals and their fixes, loops, frames, damaged parts, a fuzz run of random edits, seamless tiling of every maker and of a made material, cache hits after each kind of change, seeds, the same result on 1 to 16 cores, empty and unknown boxes, the cache budget. `boxes/tests_each.rs`: every box's outputs in range, seamless tiling (standard and other settings), the same pictures for the same seed on any number of cores and others for another seed, every setting at its extremes with the smallest and largest real-world sizes, flat inputs, what each box does, the colour-to-shape fix, lengths following the real-world size (and only those boxes made again), and a stone-tiles graph end to end. `graph_speed` and `box_speed` (ignored) time a graph and the heavier boxes by hand.
